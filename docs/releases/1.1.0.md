# DockOver 1.1.0

[简体中文](#简体中文) · [English](#english)

## 简体中文

解压 Windows x64 便携包后，运行 `DockOver.exe` 启动程序坞和菜单栏，或运行 `DockOver Desktop.exe` 启动桌面小组件和叠放。在「设置 → 外观 → 语言」选择「简体中文」。

- **音乐**支持专辑封面壁纸、动态封面、桌面歌词、全屏正在播放、自定义 LRC 和歌词时间偏移。歌词背景随音乐律动。
- **DockDrop**可从程序坞右键打开。支持手机光泡配对、二维码、文件和文字双向传输以及已配对手机重连。
- **桌面**新增 DockDrop 暂存小组件，可拖入文件或粘贴文字。程序坞支持拖入固定应用，并可拖出移除。
- **黑洞可视化预览**可从 `runtime/docky-blackhole.exe` 启动。

音乐壁纸在 16:9 和 16:10 下已完成从 720p 到 4K 级别的静态画面检查。混合 DPI 双屏、4K 动态播放性能和实体手机互传仍待扩大验证。

从 GitHub Release 下载便携包和功能截图。也可以单独使用 DockDrop 或 DockOver Music Player。 [DockOver 1.1.0](https://github.com/Davizcbia/DockOver/releases/tag/1.1.0) · [DockDrop](https://github.com/Davizcbia/DockDrop) · [DockOver Music Player](https://github.com/Davizcbia/DockOver-Music-Player)

## English

Extract the Windows x64 portable package. Start the Dock and menu bar with `DockOver.exe`, or start desktop widgets and Stacks with `DockOver Desktop.exe`. Choose English or Simplified Chinese in **Settings → Appearance → Language**.

- **Music** adds album-art wallpaper, motion artwork, desktop lyrics, full-screen Now Playing, local LRC files, lyric timing, and music-reactive backgrounds.
- **DockDrop** opens from the Dock context menu. Use the pairing bubble or QR code for two-way file and text transfers and reconnect to a remembered phone.
- **Desktop** adds a DockDrop staging widget for dropped files and pasted text. Drag apps into the Dock to pin them, or out of the Dock to remove them.
- **Black Hole** is a visualization preview available as `runtime/docky-blackhole.exe`.

Static wallpaper rendering was checked at 16:9 and 16:10 from 720p through 4K-class resolutions. Mixed-DPI displays, sustained 4K motion playback, and physical-phone transfers still need broader testing.
