# DockOver 1.4.1

[简体中文](#简体中文) · [English](#english)

## 简体中文

### 从 1.4.0 升级前请注意

1.4.0 自带的更新器不会关闭 DockDrop 和音乐组件。如果它们开着，更新会在约一分钟后失败，旧版本保持不变。请先退出 DockDrop 和音乐，再在「设置 → 关于」里更新；如果已经失败，关掉提示里列出的程序后再试一次即可。1.4.1 起的更新器会自动关闭这些组件。

### 新功能

- **DockDrop 已配对手机**：DockDrop 窗口在附近的电脑之后列出已配对的手机。点一下手机，在手机上打开 DockDrop 扫码页即可自动连接，不用再扫码。
- **菜单栏网速和温度**：可在「设置 → 菜单栏」分别开启。网速显示上传和下载；温度显示 CPU 和 GPU，读不到时显示「--°」。两项默认关闭。
- **菜单栏右键**：在隐藏图标列表里右键某个程序，可以把它放到菜单栏；在菜单栏上右键图标可以移除。程序原来的右键菜单改到「<应用> 选项…」。
- **程序坞右键菜单**：新增添加应用、添加系统快捷方式（此电脑、控制面板、下载等）、锁定图标拖动、显示或隐藏任务栏、打开工坊。开发用的选项收进「开发者」子菜单。
- **图标遮罩底板**：底色改为图标自身颜色的柔和渐变，并带顶部高光，不再是单一纯色。
- **菜单栏渐变长度**：可调到 300%。
- **程序坞**：新增底部偏移（0–25%）；新增默认的 Windows 状态块（时间、日期、电池、Wi‑Fi、音量和蓝牙）。
- **显卡选择**：默认使用独立显卡，可改用集显；核显上的程序坞模糊和应用窗口背景更省资源。
- **应用窗口**：搜索同时查应用和文件，也可以转到 Windows 搜索；识别各个 Steam 库里的游戏，并和软件、工具分开。
- **套件更新**：一次更新整个套件（DockOver、DockOver Desktop、内置 DockDrop 和音乐播放器），只关闭要替换的程序，传输中的文件可以先传完。
- **独立版 DockDrop 与音乐播放器**：检测到 DockOver 套件时，改用套件内置的版本，避免两份同时运行。

### 修复

- 程序坞状态块的充电闪电放大时顶端被裁掉。
- 台前调度切换窗口组时，程序坞里多出最小化的项目。
- 设置里「菜单栏渐变」开关和「渐变不透明度」滑块按下时会一起放大。
- 设置搜索搜不到「更新」。

## English

### Before updating from 1.4.0

The updater in 1.4.0 does not close DockDrop or the music components. If they are running, the update fails after about a minute and the old version is kept. Quit DockDrop and the music player first, then update in **Settings → About**. If an update already failed, close the programs it lists and try again. From 1.4.1 on, the updater closes these components itself.

### New

- **Paired phones in DockDrop**: the DockDrop window lists paired phones after the nearby PCs. Click a phone, then open the DockDrop scanner on that phone. It connects without scanning again.
- **Network speed and temperature in the menu bar**: turn each on in **Settings → Menu Bar**. Speed shows upload and download. Temperature shows the CPU and GPU, or "--°" when a reading is unavailable. Both are off by default.
- **Menu bar right-click**: right-click an app in the hidden icons list to show it in the menu bar, and right-click an icon in the menu bar to remove it. The app's own menu moves to "<App> Options…".
- **Dock context menu**: add apps, add system shortcuts (This PC, Control Panel, Downloads and more), lock icon dragging, show or hide the taskbar, and open the Workshop. Developer options move to a Developer submenu.
- **Icon mask backing**: a soft gradient from the icon's own colours with a highlight at the top, instead of a single flat colour.
- **Menu bar gradient length**: up to 300%.
- **Dock**: a bottom offset (0–25%) and a default Windows status block (time, date, battery, Wi‑Fi, volume and Bluetooth).
- **Graphics**: uses the discrete GPU by default, with an option for the integrated GPU. Dock blur and the Applications backdrop cost less on integrated graphics.
- **Applications**: search covers apps and files and can continue in Windows Search. Games from all Steam libraries are listed apart from software and tools.
- **Suite updates**: one update covers DockOver, DockOver Desktop and the built-in DockDrop and music player. Only the programs being replaced are closed, and running transfers can finish first.
- **Standalone DockDrop and Music Player** hand over to the copies inside the DockOver suite when the suite is present, so two copies never run at once.

### Fixes

- The charging bolt in the Dock status block lost its tip when magnified.
- Stage Manager added minimized items to the Dock when switching window groups.
- In Settings, the menu bar gradient switch and the gradient opacity slider were highlighted together when either was pressed.
- Settings search did not find "update".
