# DockOver 1.3.1

## 简体中文

- 音乐播放器优先采用同一录音的逐词歌词。本地逐行歌词可先显示，找到逐词版后自动切换。
- 逐词歌词采用渐变扫亮，长音带柔光和轻微上浮，换行时前后两句平滑交接。全屏中按 Shift 加方括号，可按 50 毫秒调整并保存当前歌曲的歌词偏移。
- DockDrop 最小化或退到后台后，可从 Windows 通知区域恢复。统一窗口从后台恢复到手机配对页时，仍可用左上角返回键。
- DockDrop 设置使用磨砂面板、连续曲线圆角和液态玻璃开关，修复按住开关时的闪烁。

Windows x64。解压后运行 `DockOver.exe`，或运行 `DockOver Desktop.exe` 打开桌面小组件与叠放。

## English

- Now Playing prefers word-synced lyrics for the same recording. Local line-synced lyrics can appear while the app looks for a word-synced match.
- Lyrics use a soft word-by-word sweep, a subtle lift and glow on sustained words, and smoother line transitions. In full screen, hold Shift and press a bracket key to adjust and save the current track’s lyric offset in 50 ms steps.
- Restore DockDrop from the Windows notification area after minimizing or sending it to the background. The Back button remains available when reopening phone pairing from the background.
- DockDrop Settings uses frosted panels, continuous corners, and liquid-glass switches. Holding a switch no longer flickers.

Windows x64. Extract the ZIP and run `DockOver.exe`, or start desktop widgets and Stacks with `DockOver Desktop.exe`.
