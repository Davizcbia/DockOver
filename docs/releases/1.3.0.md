# DockOver 1.3.0

[简体中文](#简体中文) · [English](#english)

## 简体中文

解压 Windows x64 便携包后，运行 `DockOver.exe` 启动程序坞和菜单栏，或运行 `DockOver Desktop.exe` 启动桌面小组件和叠放。

- **DockDrop 0.3.0 电脑互传**：DockDrop 打开后会查找同一局域网中正在接收的电脑。点电脑的水球、选择文件并输入对方显示的配对码即可发送；也可以把这台电脑设为接收端。对方确认后两个水球融合，保存完成后显示完成。同名文件会自动改名保存，配对码输错可以重新输入。电脑互传需要 .NET Desktop Runtime 9 或 10。
- **DockDrop 一个界面**：发现电脑和配对手机在同一个窗口里。点「配对手机」时水球连续放大到配对页，周围的界面淡入淡出；左上角「‹」返回。DockDrop 已在后台运行时，从程序坞再次打开会回到同一个窗口。
- **DockDrop 更省、更稳的重连**：每台电脑只保持一个「门铃」连接，记住的手机通过敲门唤起电脑后再直接连接，不再为每台手机长期占用连接；二维码只在配对页显示时才挂起。配对服务暂时不可用时显示明确提示，并逐步延长重试间隔。手机扫码页同步支持新的静止备用光纹。
- **窗口预览**改用与右键菜单相同的液态玻璃：顶部显示应用图标和名称，每个窗口一张卡片，带关闭、最小化、缩放按钮和标题，圆角层层同心。
- **菜单栏**的 DockOver 菜单新增睡眠、重新启动…、关机…、锁定屏幕和注销…；带「…」的操作会先确认，不会强制关闭应用。菜单在中文界面下统一显示中文。
- **任务栏**：上一次保存被中断时留下的临时记录不再导致「隐藏任务栏」一直失败，残留文件会被保留备查。
- **真全屏**也覆盖隐藏任务栏所占的边缘，退出后菜单栏和程序坞的空间正确恢复。

DockDrop 电脑互传尚未在两台实体电脑之间完整验证；门铃重连和新的备用光纹仍需在实体手机上验证。

## English

Extract the Windows x64 portable package. Start the Dock and menu bar with `DockOver.exe`, or desktop widgets and Stacks with `DockOver Desktop.exe`.

- **DockDrop 0.3.0 PC to PC**: DockDrop looks for PCs on the same network that are receiving. Click a PC's water ball, choose a file and enter the code it shows, or make this PC a receiver. When the other side accepts, the two balls merge and the transfer finishes once the file is saved. A file with the same name is saved under a new name, and a mistyped code can be entered again. PC transfer needs .NET Desktop Runtime 9 or 10.
- **DockDrop in one window**: finding PCs and pairing a phone share one window. Choosing Pair phone grows the water ball into the pairing page while the rest cross-fades; the **‹** button goes back. If DockDrop already runs in the background, opening it from the Dock returns to the same window.
- **DockDrop reconnects more cheaply and reliably**: each PC keeps a single "doorbell" connection; a remembered phone knocks to wake the PC and then connects directly, instead of each phone holding its own connection. The QR code only waits while the pairing page is shown. When the pairing service is unavailable, DockDrop says so and retries less and less often. The phone scanner reads the new still backup pattern.
- **Window previews** use the same liquid glass as the context menus: the app's icon and name on top, one card per window with close, minimize and zoom buttons and its title, with concentric corners.
- **Menu bar**: the DockOver menu adds Sleep, Restart…, Shut Down…, Lock Screen and Sign Out…; the commands with "…" ask first and never force apps to close. Menus show Chinese throughout in the Chinese interface.
- **Taskbar**: a temporary record left by an interrupted save no longer makes Hide taskbar fail every time; the leftover file is kept for review.
- **Real full screen** also covers the strip of the hidden taskbar, and the menu bar's and Dock's space comes back correctly afterwards.

PC to PC transfer has not yet been fully tested between two physical PCs; doorbell reconnection and the new backup pattern still need testing on physical phones.
