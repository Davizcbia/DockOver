### 放大状态（Dock 窗口抓图，光标在 Calendar 上）

| 距光标的格数 | 本体宽度（2× 像素） | 缩放 |
| --- | --- | --- |
| 0 | 208 | 2.26 |
| ±1 | 192 / 190 | 2.09 / 2.07 |
| ±2 | 150 / 150 | 1.63 |
| ±3 | 100 / 100 | 1.09 |
| ±4 | 92 | 1.00 |

- **放大曲线**：把 (s-1)/(smax-1) 归一化后，距 1 格为 0.85，2 格为 0.50，3 格为 0.07，4 格为 0。余弦衰减取半径约 3.6 格时与此最接近（预测值 0.83 / 0.41 / 0.07）。【待验证】确切曲线，以及衰减距离按静止位置还是放大后的位置计算。
- **间距随放大一起扩大**：相邻图标的中心间距约等于 60×(sᵢ+sⱼ)/2（实测 162、218、254 对比预测 163、223、261）。也就是说，每个图标占用的格宽是 pitch×s，图标间距也跟着放大（28→54 px）。
- **放大图标的底部会上移**：缩放 1.63 时上移 3 pt，2.26 时上移 6.5 pt，约为 (s-1)×0.11×图标本体。原因是 macOS 图标画布底部自带约 10% 留白，而缩放锚点在画布底边。
- **底板高度不变**，只横向变宽：抓图中 +278 pt，全屏截图中 +298 pt。
- **锚定规则**：悬停中段时，底板中心保持在 2560 px，对称扩展，被悬停的图标仍在光标下（相差 6 px 以内）。悬停右端时，左侧扩展 139 pt、右侧扩展 96 pt。这两种情况都与 V0.1 的“光标下内容固定”模型一致。【待验证】最两端时的精确规则。
- **名称标签**：胶囊形，85×25 pt（Calendar 这个词），两端全圆角，底色灰约 36/255，文字白色。下方有一个约 16×6 pt 的指向三角，箭头尖离图标顶部 16 pt。字号据 25 pt 胶囊高度估算约 13 pt。在全屏截图中标签呈半透明玻璃质感。【待验证】具体透明度。

### 材质（全屏合成截图）

- **颜色**：深色烟灰玻璃，背景细节完全被模糊掉。用亮、暗两处背景做线性拟合，底板颜色约等于 **46% 模糊后的背景 + 54% 灰（亮度约 0.21）**。这是基于两个采样点的估算，【待验证】。
- **模糊半径**：明显的背景纹理全部消失，推测 σ ≥ 15 pt。【待验证】
- **边缘**：0.5 pt 发丝亮边绕满一周。内侧有一圈很淡的亮带（边缘折射）。控制中心截图里，背后的桌面图标在圆角边缘有明显的拉伸和弯折，说明 Liquid Glass 带有边缘折射。
- **图标**：没有投影，直接叠在玻璃上。

## 5. V0.2 范围建议

- **做（只改参数和绘制，不改 240 FPS 架构）**：
  - 第 3 节 #2–#7：比例、放大曲线、tile 布局、底部上移、发丝亮边、squircle、去掉图标投影、胶囊标签加三角、指示点。
  - #8 分隔线（配置中的 `---`）。
  - 深烟灰着色，作为 P0.3 到来之前的近似效果。
- **需要你决定**：在 P0.3 之前是否加一个过渡模糊。
  - 方案 A：等 P0.2/P0.3，V0.2 继续用不带模糊的烟灰色。
  - 方案 B：先用 DWM 系统 backdrop 或 acrylic，在 Dock 后面放一个底板形状的窗口来得到系统模糊。代价是圆角要靠窗口区域裁剪，会有锯齿，或者需要使用未公开的 API；系统模糊也不可控，日后会被 P0.3 替换。
- **不做**：角标、堆栈和扇形展开、浅色模式、自动隐藏、精确的动态手感（等视频测量后再定）。

## 6. 对现有约束的影响

- 动画时钟、按需渲染和 `IBackdropSource` 边界都不需要改动。新增的成本只有每帧重建一次 squircle 几何体、绘制胶囊标签和三角，可以忽略。
- 不涉及 `prototype/`（P0.2）和 Qt Lab，不在 master 上开发，`ref/` 下的截图不提交。

## 8. 尚未还原的视觉差异（按影响程度排序）

1. **背景模糊与折射**：依赖 P0.2 捕获和 P0.3 着色器。V0.2 的烟灰色材质在纹理丰富的壁纸上会透出清晰的细节，而 macOS 是完全模糊的。接口已经预留：`IPlateMaterial` 和 `PlatePaint.backdrop`。
2. **图标外形**：macOS 图标统一为 squircle 底板，Windows 图标形状各异（宽文件夹、带透明区的图标），所以视觉上的“大小一致感”不如 macOS。如需改善，可以考虑可选的统一底板或按图标内容面积做光学尺寸补偿，属于 V0.3 候选，【需决定】。
3. **标签材质与字体**：用烟灰半透明近似 macOS 的玻璃标签；字体用 Segoe UI 代替 SF Pro，字宽略有不同。
4. **放大衰减尾部**：R=4 格时，距 3 格处的缩放为 1.15，macOS 为 1.09，尾部略宽。【待验证】需要视频确认衰减曲线和光标是否精确对准图标中心。
5. **两端锚定**：光标在最左端内边距时，V0.2 只向右扩展；macOS 在右端实测为左 139 / 右 96 的非对称扩展。确切规则【待验证】。
6. **分隔线是否随放大变宽**：V0.2 的分隔格按自身位置的缩放值变宽。【待验证】
7. **动态手感**：进入和离开的时间常数（75/130 ms）、光标跟随（35 ms）、启动弹跳（21 DIP，2 次，0.95 s）、标签淡入，都未与 macOS 视频对照。【待验证】
8. **边缘细节**：在 100% 缩放下 1 物理像素的发丝线比 Retina 上的 0.5 pt 显得粗一些；内侧折射带只是很弱的近似；底板投影用的是圆角矩形而不是 squircle。
9. **未实现**：角标、浅色模式、堆栈和扇形展开、自动隐藏。
10. **窗口余量**：悬停时整窗命中区高 196 DIP，比 V0.1 高 10 DIP，静止时仍只覆盖底板。
