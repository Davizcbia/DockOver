**Glass Lab 渲染管线（按源码确认）：**
1. 背景场景被渲染成清晰纹理（全分辨率）。
2. 对清晰纹理做 MultiEffect 高斯模糊，半径 = `blurSpread × 40 px`。
3. 以半分辨率捕获模糊结果。
4. 单个片元 Shader 在玻璃自身的矩形（四周外扩 12 px，用于投影）内逐像素计算：
   - 有符号距离场（SDF）轮廓与抗锯齿覆盖率；
   - 外部投影；
   - 斜面法线与基于折射率的折射位移；
   - 背景放大；
   - RGB 分通道色散（只采样清晰纹理）；
   - 清晰与模糊的混合（雾化）；
   - 饱和度与亮度调整、高光柔和压缩；
   - 深色/浅色玻璃着色（浓度、深色提亮）与控件着色；
   - 描边；
   - 光照：固定反射模式下是顶部、底部亮线和底部辉光，动态模式下是菲涅耳、镜面和轮廓光；
   - 指针悬停与按压反馈；
   - 预乘 alpha 输出，再乘以 qt_Opacity。

## 2. 许可证结论与实现边界

- Glass Lab 的 Shader、QML 和宿主 C++ 都是 **GPL-3.0-only**，Dock 项目目前没有任何 LICENSE 文件。
- 按用户要求，**不复制、也不逐行翻译** `liquidglass.frag` 等受保护的实现。
- Dock 的 HLSL（`dockui/shaders/glass.hlsl`、`blur.hlsl`）依据下列内容**独立编写**：
  - 本文第 3 节的**效果需求**（每个参数“做什么”）；
  - 公开、通用的图形学方法：超椭圆 SDF、Snell 折射（HLSL `refract`）、可分离高斯模糊、亮度保持的饱和度调整、Schlick 型菲涅耳、半角向量镜面光；
  - 对 Lab 的视觉对照。
- 参数**名称、默认值和范围**沿用 Lab 的 JSON 键。这属于参数接口和数据兼容，用于“粘贴 Glass Lab JSON”导入，不是复制实现。
- 两边的函数结构、混合曲线和常数并不一一对应，所以**同一组参数下画面相近，但不保证逐像素相同**。
- **待用户决定**：如果用户是 Glass Lab 的版权持有人，或者愿意让 Dock 以 GPL-3.0 发布，就可以改成忠实翻译以获得逐像素一致。在决定之前保持独立实现。

**Lab 中存在、本次不移植的功能**（没有对应的 Dock 场景，不会伪装成已实现）：
- `materialVariant` 的五种对照模式；`reduceBrightEffects`、`increaseContrast`、`frostedMode`（这些是辅助功能模拟和动画）。
- `fusionEnabled`/`fusionDistance` 和胶囊融合。
- 前景文字折射（`foregroundTexture`、`lensLabelRange`）。
- 大面积玻璃样式 `cardStyle`/`softTexture`、按压透镜 `flatBevel`。
- `sidebar*`（侧栏光晕）、`slider*`（Lab 滑块专用材质）、`reducedMotion`。

**与建议分组的对应：**
- Corner Radius → `radius`，Edge Width → `bevelWidth`。
- **Glass Thickness：Lab 没有这个参数**。透镜深度由 `bevelWidth × refraction` 推导，因此不提供单独的滑块。
- Blur Radius → `blurSpread`（以及 `frost`），Refraction Strength → `refraction`（以及 `refractiveIndex`），Chromatic Dispersion → `dispersion`。
- Edge Highlight → `edgeAmount` 和固定上下亮线；Light Direction → `lightAngle`、Specular Strength → `specularAmount`，两者只在动态反射模式下生效，界面上会注明。
- Opacity → `opacity`，Tint → `tint`。

**Dock 新增、Lab 没有的设置**（界面上标为“Dock”）：
- **Blur Quality**：模糊纹理的降采样倍数。Lab 固定为 1/2；需要重建纹理时延迟合并处理。
- **Debug Visualization**：查看 SDF、法线、折射位移、模糊纹理。
- **Backdrop**（背景来源）：在 WGC 捕获集成之前，只有**模拟背景**（静态壁纸 / 网格 / 渐变 / 纯色）。
- **Continuous render**：基准测试用的持续渲染。
- **Background Update Rate**：P0.2 捕获尚未接入；静态模拟背景没有更新率，这一项不提供，记为 P0.2 待办。

## 4. 移植设计

- **材质接口**：`IPlateMaterial` 增加 GPU 路径（`UsesGpu` / `CreateGpuResources` / `RenderGpu`）。
  - `LiquidGlassMaterial` 在 D2D 绘制之前，用 D3D11 直接把玻璃画进交换链的后台缓冲区（预乘 alpha），之后 D2D 只叠加图标、分隔线、指示点和标签。
  - `SmokeMaterial` 保持 V0.2 的 D2D 路径，作为回退材质：没有背景、GPU 资源创建失败，或用户选择 Smoked 时使用。
- **背景**：沿用 `IBackdropSource`。新增 `SimulatedBackdropSource`，用 `IDesktopWallpaper` 读取当前显示器的壁纸，按 Fill/Fit/Stretch/Center 方式铺到显示器尺寸的纹理上（WIC 解码）。也可以选网格、渐变、纯色测试图。所有模式在 UI 和日志中都标明“模拟背景”。P0.2 的 WGC 将来实现同一接口即可替换。
- **模糊**：只处理 Dock 窗口区域加外扩边距（ROI），不做全屏模糊。
  - 先降采样（默认 1/2，与 Lab 一致），再做水平、垂直两遍可分离高斯（GPU）。半径来自 `blurSpread`，取自常量缓冲区。
  - 只在背景帧号、窗口矩形、模糊半径或质量变化时重新计算，否则复用缓存。
  - 质量（降采样倍数）变化需要重新分配纹理：标记为脏，在下一帧合并处理。
- **玻璃 Pass**：一个全窗口三角形；像素着色器做 SDF 覆盖率、投影、斜面法线（SDF 中心差分）、`refract` 位移、放大、色散采样、雾化混合、颜色处理、着色、描边、固定反射或动态光照、交互、调试视图。没有分支切换 Shader，开关都是常量缓冲区里的标志。
- **参数**：`GlassParameters` 是平铺的 POD 结构。
  - `GlassSettingsStore` 用互斥锁保护参数和预设，加一个原子版本号；锁内只做结构体拷贝，不涉及 GPU 等待。
  - 渲染线程每帧比较版本号，只在变化时拷贝快照，再 `Map/Unmap`（`WRITE_DISCARD`）常量缓冲区。
- **Glass Studio**：独立线程上的独立 Win32 窗口，有自己的消息循环。拖动或缩放调参窗口的模态循环不会卡住 Dock 的渲染线程。
  - 修改参数后，通过 `PostMessage` 通知 Dock 按需绘制一帧。
  - 关闭窗口不影响 Dock。
  - 参数以 JSON 保存在 `%LOCALAPPDATA%\LiquidDock\glass.json`：当前值、用户默认值、预设。先写临时文件再原子替换；文件损坏时备份为 `.corrupt` 并回退到默认值。
  - 支持“粘贴 Glass Lab JSON”（version 3 的键），超出范围的数值会被截断。
- **性能统计**：
  - CPU 帧时间：在 QPC 上测 `Frame()` 的耗时。
  - GPU：用 D3D11 时间戳查询加 disjoint 查询测玻璃和模糊 Pass，环形缓冲，非阻塞读取（`D3D11_ASYNC_GETDATA_DONOTFLUSH`），disjoint 时不显示。
  - 帧率沿用现有的帧率和 DXGI 统计。
  - Studio 每 250 ms 读取一次原子发布的统计值。这个定时器只用于刷新界面，不驱动 Dock 动画。
- **约束**：动画时钟、按需渲染和 240 Hz 节拍不变；调参不阻塞渲染；静止且背景不变时停止重绘。

## 6. M2 结果：Liquid Glass 材质（2026-11-05）

- **新增文件**：`shaders/glass.hlsl`、`shaders/blur.hlsl`（构建时由 fxc 编译成字节码头文件，`/WX` 零警告）、`src/liquid_glass.cpp`、`src/backdrop_sim.*`、`src/glass_params.*`、`src/json_lite.*`。
- **接入方式**：`IPlateMaterial` 新增 GPU 路径；Renderer 依次执行 D3D 清屏、玻璃 Pass（含模糊）、D2D 绘制图标和标签。没有背景、选择了 Smoked 或 GPU 失败时，回到 V0.2 的 D2D Smoked 材质。
- **背景**：只有**模拟背景**，即静态壁纸（`IDesktopWallpaper` + WIC，2560×1440，构建约 50 ms，在工作线程完成）、网格、渐变、纯色。日志、F1 叠加层和 Studio 都标明了“SIMULATED”。
- **调试视图**确认了几何与光学：
  - SDF 等距带平行于连续曲率轮廓；
  - 法线只在斜面带内倾斜；
  - 折射位移只出现在边缘，中心为 0；
  - 模糊纹理正确；
  - 网格背景放大 3 倍后，可见左端曲边处网格线弯折，并带红/蓝色散。
- **性能**（单屏 2560×1440、96 DPI、240 Hz、RTX 5070 Ti Laptop，最终二进制，持续渲染）：

| 材质 | 帧率（1 s 窗口） | CPU | GPU 帧 | 其中玻璃 Pass |
| --- | --- | --- | --- | --- |
| Liquid（壁纸背景） | 235–240 fps，DXGI 稳定窗口 238 次呈现 / 238 个 vblank | 0.42–0.47 ms | 0.27–0.60 ms | 0.25–0.58 ms |
| Smoked | 237–240 fps | 0.47–0.58 ms | 0.08–0.27 ms | — |
| Liquid，普通悬停动画（verify.ps1） | 236–240 fps | 0.42–0.60 ms | 0.25–0.77 ms | — |

- **测量口径**：GPU 时间来自 D3D11 时间戳与 disjoint 查询，覆盖本帧提交的 GPU 命令，不含 DWM 合成。
- **模糊开销**：模糊只在背景帧、ROI、半径或质量变化时重算（ROI 623×146，半分辨率）。偶发单个 8.4 ms 帧间隔（漏一个 vblank）在两种材质下都有，与玻璃无关。

## 7. M3 结果：Glass Studio（2026-11-05）

- **窗口**：`src/glass_studio.*`，独立线程、独立消息循环，可移动、可调整大小、可关闭（Esc 也会关闭 Studio 本身，不影响 Dock）。从 Dock 右键菜单的 “Glass Settings…” 或 `--studio` 打开。
- **控件**：
  - 31 个数值参数：滑块与数字框双向同步，越界时截断，非法输入恢复原值。
  - 3 个开关。
  - 材质（Liquid / Smoked）、背景（模拟）、调试视图、模糊质量（Dock 设置）、持续渲染基准开关。
  - 预设的加载、保存、重命名、删除；内置 “Glass Lab defaults” 和 “Launcher tuned” 两套预设。
  - 恢复默认、保存为默认、粘贴 Glass Lab JSON、复制 JSON、着色取色。
  - 每 250 ms 刷新的 FPS、CPU、GPU 统计（GPU 尚未可靠测得时显示“not yet measured”）。
- **参数通路**：Studio 写入 `GlassSettingsStore`（互斥锁只保护结构体拷贝，原子版本号），再 `PostMessage` 通知 Dock 重绘一帧。Dock 每帧比较版本号后取快照，`Map(WRITE_DISCARD)` 常量缓冲区。
  - 滑块调整不重新编译 Shader、不重建 GPU 资源。
  - 只有模糊质量（降采样倍数）变化时，在下一帧重建 ROI 纹理。
  - 参数在 600 ms 去抖后保存到 `%LOCALAPPDATA%\LiquidDock\glass.json`（测试使用 `--glass-config` 指定的独立文件），关闭 Studio 时也会保存。
- **验收**（`verify_glass.ps1 -StudioOnly`，最终二进制，全部通过）：
  - 右键菜单打开 Studio（真实右键与键盘操作）。
  - 键盘 Home 把雾化滑块调到 0，数字框随之显示 0.000。
  - 在数字框输入 38，滑块到达最大值（1000）；输入 999 时截断为 38.0。
  - Dock 实时变化（采样像素变化 3038）。
  - 切换到 Smoked 后画面变化（3084）。
  - 预设保存、重命名、加载内置预设（brightness 0.81、frost 0.300）、加载用户预设、删除（含确认对话框）。
  - 保存为默认后，恢复默认得到 0.000。
  - 粘贴 Lab JSON：frost 0.120、dispersion 0.200，radius 按设计忽略；非法 JSON 整份拒绝，参数不变。
  - 关闭 Studio 后 Dock 仍在运行，`glass.json` 中保存了 0.12。
  - 损坏的配置文件被备份为 `.corrupt`，并回退到默认值。
- **调参时的帧率**：开启持续渲染后，连续按方向键 2.5 s 调整色散，再拖动 Studio 标题栏移动窗口 2.5 s，Dock 保持 **234–240 fps**（最大帧间隔约 8.4 ms），说明 Studio 没有把 Dock 拖到 60 FPS。

## 8. 尚未完成与待验证

1. **背景仍是模拟的**：静态壁纸看不到 Dock 后面的窗口；动态壁纸（Wallpaper Engine）、多屏背景同样没有。需要 P0.2 的 WGC 实现 `IBackdropSource` 后替换。“Background Update Rate”也要到那时才有意义。
2. **与 Glass Lab 只做到同参数下效果相近，未逐像素对照**：HLSL 是独立实现，混合曲线和常数与 Lab 不同。模糊半径的换算（σ = 半径 / 2.5）是近似值，没有在同一背景下与 Lab 截图做逐像素比较。是否改为忠实翻译取决于许可证决定（第 2 节）。
3. **Lab 中未移植的功能**：材质变体、辅助功能模拟、融合、前景文字折射、大面积玻璃样式、按压透镜、侧栏光晕（第 3 节）。
4. **交互效果**：在默认的固定反射模式下，指针悬停几乎不改变光照，与 Lab 一致；按压加深透镜已实现，但未单独做视觉验证。
5. **右键菜单期间 Dock 停止渲染**：`TrackPopupMenu` 的模态循环在 Dock 线程上运行，菜单打开期间 Dock 不出帧（日志中出现一个 50 ms 间隔）。这与 Studio 无关，属于既有限制。
6. **Studio 的外观与测试覆盖**：使用系统浅色控件，没有深色主题；只在 96 DPI 下测试过，`WM_DPICHANGED` 的布局代码未实测。
7. **GPU 计时口径**：只覆盖本进程提交的命令，不含 DWM 合成和扫描输出；实际显示时序需要 PresentMon/ETW。
