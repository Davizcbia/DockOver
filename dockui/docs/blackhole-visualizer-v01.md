# Black Hole Visualizer v0.1（DockDrop 视觉基础）

2026-11-22（同日第二轮：默认去掉吸积盘，加入载荷动画）。独立程序 `docky-blackhole.exe`，只实现黑洞视觉，不含 DockDrop 的网络连接、设备发现或文件传输。不被 Desktop Manager 启动，不链接进 Dock、Menu Bar、Control Center 或 Now Playing。

## 运行

- 构建：`build-blackhole` 是独立 CMake/Ninja 目录，只构建 `DockyBlackHole` 与 `DockyBlackHoleTest` 两个目标（不重编、不覆盖其他正在运行的 DockOver 程序）。完整构建 `build_docky.cmd` 也会包含这两个目标。
- 启动：`run_blackhole.cmd`，或 `build-blackhole\docky-blackhole.exe [选项]`。退出：关闭面板，或 `docky-blackhole.exe --quit`。
- 物理/动画单元测试：`build-blackhole\DockyBlackHoleTest.exe`。

| 选项 | 作用 |
|---|---|
| `--quality high\|balanced\|low` | 性能档（默认 balanced） |
| `--test-pattern` | 用标定网格代替桌面（检查透镜几何） |
| `--no-panel` | 不显示参数面板（Ctrl+Alt+B 可切换面板） |
| `--size <DIP/M>` `--lens <M>` `--tidal <0..3>` | 初始参数（`--tidal` 默认 0：图标不拉伸） |
| `--disk` `--incl <度>` `--glow <0..1>` | 打开可选的吸积盘（默认关闭，只有圆形透镜） |
| `--no-shred` `--drift <0..1>` | 关闭图标撕碎成像素 / 天空漂移幅度（默认 0.6，0 = 静止） |
| `--demo infall\|emit\|loop` | 脚本演示：文件夹图标从场边缘靠近并坠入 / 从黑洞喷出 / 每 4.5 s 交替 |
| `--demo multi-infall\|multi-emit\|multi` | 三个文件（文件夹、图片、压缩包）：成叠拖入、间隔 0.12 s 依次松手（与真实多文件拖放同一路径）/ 间隔 0.28 s 喷到三个位置 / 每 6 s 交替。面板按钮 "Multi-file test" 先拖入三个再喷出三个 |
| `--snapshot-seq <dir> [--snapshot-interval <s>] [--snapshot-count <n>]` | 从 `--snapshot-after` 起按间隔保存序列帧（覆盖窗口不进截图，用这个看动画；显示器关闭时用 `--test-pattern`） |
| `--x <px> --y <px>` | 黑洞中心（物理屏幕像素） |
| `--snapshot <file.bmp> [--snapshot-after <s>]` | 保存镜头渲染目标（覆盖窗口本身被排除在截图之外，截图工具看不到它） |
| `--bench <每档秒数> [--bench-out <file>]` | 依次测量 High / Balanced / Low，写报告后退出 |
| `--pump-wait <ms>` | 绘制前等待新桌面帧的上限（默认 1；0 实测多约 2.8 ms 延迟） |
| `--exit-after <s>` `--log <file>` `--quit` | 测试辅助 |

鼠标（只在黑洞阴影附近接收，其余区域点击穿透）：拖动 = 移动（带可调惯性的临界阻尼弹簧跟随）；滚轮 = 尺寸；Ctrl+滚轮 = 透镜强度；Shift+滚轮或右键上下拖 = 吸积盘观察角（盘关闭时无效果）；双击 = Consume 预览。

拖文件：从资源管理器把文件拖进透镜场（按住左键期间整个场可接收 OLE 拖放），图标被吸引、潮汐拉长，松手后螺旋坠入；多选时最多 3 个图标成叠依次落入。只是视觉效果：程序不读取、不复制、不移动文件（向拖放源返回 COPY，源文件不受影响），系统拖放图像被隐藏，由本程序绘制图标。面板上 "Drop a test icon in" / "Emit a test icon" 按钮可直接预览。

## 架构

- `src/blackhole/schwarzschild_lut.h`：Schwarzschild 零测地线（Binet 方程 u'' = 3u² − u，RK4，步长 5e-4 rad）。预计算 1024×1024 表 u(b, φ) 与 1024 列 φ_end(b)；b 列在 b_c = 3√3 附近对数加密，b_c 恰在两列之间，着色器不会跨捕获边界插值。启动时多线程构建约 18 ms。
- `shaders/blackhole.hlsl`：每像素一条光线（远处观察者，正交相机，b = ρ / pxPerM）。
  - b < b_c：光子被捕获，纯黑阴影；1 spp 时按一像素宽度的 b 做解析覆盖率抗锯齿。
  - 背景：逃逸方向 φ_end = π + α，桌面作为洞后的"天空"（以反观察者方向为中心的等距方位映射）。弱场下等价于薄透镜方程 β = θ − D·α，爱因斯坦环半径 2√D M；α 接近 2πn 时形成相对论性多重像。默认 D = 7（第三轮由 30 改来）：爱因斯坦环正好落在阴影边缘，桌面朝黑洞逐渐被拉伸、沿切向绕成弧，没有 D = 30 时阴影外那圈镜像反转的"甜甜圈"带；面板 "Lens strength" 可调回大值。
  - 吸积盘：赤道面薄盘，法线随观察角倾斜。光子在 φ₀ + nπ 处穿过盘面，查表得 r；n = 0 直接像，n = 1 绕到阴影另一侧的像，n = 2 光子环像。由前到后合成（盘不透明度可调）。盘面纹理就是桌面本身（俯视映射：正视且无透镜时与原桌面逐点重合），按 Kepler 角速度 r^-1.5 转动（刚体部分 + 差速部分的双相 flow map）。
  - 盘的红移：1+z = (1 − Ω·b·eₓ·sin i)/√(1 − 3/r)，亮度 g³ 加色移（"Doppler beaming" 滑块控制强度，0 关闭）。
  - 桌面使用 mip 链 + 由像素中心梯度选 LOD，光子环附近强缩小区域不闪烁；High 4 spp、Balanced 2 spp（光子环 ±1.2 M 内 4 spp），只在 b < b_c + 3 范围超采样，弱场区单样本，保持与原桌面一样锐利。
  - 边缘：偏折量在 taperStart·R 到 0.92R 间平滑衰减到 0（为有限窗口做的非物理处理），0.94R–R 透明度淡出。测试图实测 0.925–0.935R 环带 3808 像素与源图逐像素一致。
- `src/blackhole/blackhole_renderer.*`：LUT 纹理、桌面 mip 拷贝（仅当采样可达区域内的桌面变化时）、GPU timestamp、BMP 快照。
- `src/blackhole/blackhole_main.cpp`：
  - 覆盖窗口：顶层、`WS_EX_LAYERED|TRANSPARENT|NOACTIVATE|NOREDIRECTIONBITMAP`、`WDA_EXCLUDEFROMCAPTURE`（桌面复制看不到它，没有捕获递归；截图键按下时沿用 `capture_visible` 冻结逻辑）。窗口覆盖黑洞所在显示器，内容是只有镜头区域大小的 DComp 交换链，用 visual transform 定位：拖动只改常量和偏移，同帧提交，不移动/不缩放窗口。
  - 桌面采样：复用 DockOver 的 `SharedDesktop`（DXGI Desktop Duplication）owner 模式——复制在渲染设备上、由渲染线程在绘制前 `PumpOwned` 取帧，省掉跨设备共享的一帧。Wallpaper Engine 等动态壁纸作为合成后的桌面画面按其自身帧率进入。HDR 桌面由 SharedDesktop 转为 SDR。
  - 渲染线程：帧延迟 waitable（最多排队 1 帧）+ `DCompositionWaitForCompositorClock` 对齐合成时钟；面板拖动等模态循环不会阻塞渲染。
  - 多显示器 / DPI：中心移到另一显示器时覆盖窗口移到该显示器，复制切换到该输出；尺寸以 DIP/M 计，按显示器有效 DPI 换算。
  - 辅助功能：Windows"动画效果"关闭时动画立即完成、盘不转；高对比度时关闭 Doppler 着色与辉光；节电模式开启时自动降为 Low power。
- `src/blackhole/blackhole_debris.h` + `shaders/blackhole_debris.hlsl`：潮汐瓦解（第四轮，参考 NASA SVS 14620 "Tidal disruption by black hole"）。
  - **第二十一轮：多文件不再停顿，碎像素更乱。** 多文件松手原先依次错开 0.12 s：光标已经松开，后面的卡片在原地减速停下，再从静止开始落，看起来停住了；现在全部同时松手（演示和真实拖放 DropTarget::Drop 都改了），每个保留自己的速度，位置本来就错开，所以各走各的轨迹。播放时钟加速改为 ∝ r^1.5（与自由落体时间同一标度：25M 处 8.5 倍、6M 以内 1 倍），每次拖入仍共用一个时钟（每块碎片各自一个时钟会让外侧追上内侧，抵消潮汐拉伸）。断裂时弹性释放的速度限制在下落速度的 1/3 以内，大块不再被弹回外面掉队。碎屑：3 个像素以下的碎块直接散成像素，每个像素额外随机飞散速度（≤ 下落速度的 1/4）、随机朝向、快速翻转（±8 Ω）、大小随机 0.55–1.45 倍。单元测试：第一块到达视界前碎成 2080 块，1.8 s 内全部被吞，每帧最大位移 0.615M。
  - **第二十轮：撕碎时不再停住。** 从静止开始的真实自由落体，远处起步极慢（r = 20M 处 0.3 s 只移动约 0.2M），而裂开恰好发生在这时，看起来像停在原地碎掉。现在每次拖入用一个统一的播放时钟，按碎片平均半径平滑加速：26M 处 5 倍、9M 以内 1 倍（轨迹仍是精确的自由落体测地线，只是远处慢的一段播得快）；开始断裂的半径从 0.95 r₀ 改为 0.85 r₀，裂开时已经在明显下落。单元测试：松手第一帧位移 0.0019M，0.77 s 时第一块到达视界，2.4 s 内全部被吞，碎成 1733 块，每帧最大位移 0.356M。
  - **第十九轮：碎得更乱。** 每次断裂碎成 2–4 块形状不规则的碎片（在碎块里随机取种子点，按最近种子划分，即 Voronoi 裂纹；距离沿径向加权，裂纹仍倾向于垂直径向；边缘锯齿化）；弹开的速度大小、方向逐块随机（弹性能释放不均匀）；碎块翻转更快（±3 Ω），散成单个像素后每个像素各自朝向、各自翻转（±4 Ω）；断裂半径随机范围 ±15 % → ±35 %。单元测试：第一块到达视界前碎成 2166 块，松手第一帧位移 0.0002M，每帧最大位移 0.173M，3.9 s 内全部被吞。
  - **第十八轮：碎得更彻底。** 图标强度降低（松手后不久就开始裂：断裂半径起点 0.95 r₀，上限 24M），小块强度随尺寸的增长变缓（断裂半径 ∝ 尺寸^0.15），所以一路碎到像素；加入两项断裂时的真实效应：应变储存的弹性能释放，两半以 ~1.2 Ω d 相互弹开；裂缝的扭矩让碎块随机翻转（±2 Ω）。碎块会互相散开、翻滚着依次落入。单元测试：第一块到达视界前已碎成 1464 块碎片，松手第一帧位移 0.0002M，每帧最大位移 0.144M，3.9 s 内全部被吞。
  - **第十七轮：撕碎改为固体在潮汐下断裂（仍然只有引力，阴影内不可见）。**
    - 图标是有强度的刚体：松手后整体沿中心的测地线下落；进入"断裂半径"时裂成两块——一道随机位置、边缘锯齿状的裂缝，在受拉方向上垂直于径向（已经沿径向又细又长的块则顺着径向裂开）。小块更结实（缺陷更少，Weibull），断裂半径 ∝ 尺寸^(1/4)、±15 % 随机，所以越往里碎得越细：大块 → 碎块 → 碎屑 → 单个像素。
    - 每块都是刚体，沿自己中心的测地线运动；裂开时两半保留原速度，再加上潮汐速度场（沿径向分开、横向挤拢，Ω = √(2/r³)），之后潮汐把它们沿各自轨道拉开，裂缝逐渐张开，靠里的碎块先落进去。像素各自画成方块（相互重叠，整体时无缝），所以裂缝就是缝隙。
    - 单元测试：松手后第一帧位移 0.0002M；4096 个像素全部被吞，3.1 s 内结束；每帧最大位移 0.136M、相邻帧变化 ≤ 0.023M。复测（--demo multi）：High 240.0 fps，p99 4.86 ms，CPU 每帧 0.61 ms；Balanced 240.1 fps；Low 58.3 fps。
  - **第十六轮：黑色阴影内什么都看不见。** 碎片像素和悬停卡片一样，只通过能逃出的光线绘制（乘以阴影边缘的抗锯齿覆盖率），落进去的像素在阴影边缘下面平滑滑入、被切掉，阴影内部始终纯黑。
  - **第十五轮：只按真实物理（自由下落 + 面条化），并保证丝滑（取代第十一至十四轮的掠过/撕裂/成环模型）。**
    - 逐帧检查发现两处既不物理也不连续：松手瞬间图标被赋予从无穷远落来的抛物线速度（每秒几十 M 的速度跳变），而真实中被放开的物体从静止开始加速；以及松手时卡片换成 32×32 平均色块，清晰度突降。
    - 现在：松手时图标的每个像素（64×64）成为自由粒子，位置就是卡片画出的位置，速度就是卡片当时的速度（拖动带来的速度，静止时约 0；`PayloadSystem::Handover` 交出速度）。之后每个像素只沿自己的类时 Schwarzschild 测地线运动，不加任何人为力：从静止开始径向下落并加速；离黑洞近的一侧落得更快、所有像素朝同一中心汇聚，图标自然沿径向拉长、横向变窄（潮汐，测地偏离）。侧向甩动会带来角动量，按测地线绕行或被捕获。
    - 远处观察者的时钟：靠近视界时像素减速、红移 g = f/E 变暗（强度 ∝ g³），在阴影边缘变红变黑消失，不会"穿过"视界。平面改回正对观察者（屏幕所在平面），去掉人为的激波耗散、加热成环、刚体阶段和远处加速播放。kTimeScale 0.026 → 0.022。
    - 单元测试：4096 个像素全部被吞；松手后第一帧位移 0.0002M（无跳变）；到第一个像素被吞时径向长度 7.8 → 15.7M、横向宽度 6.0 → 3.0M；每帧最大位移 0.135M、相邻帧位移变化 ≤ 0.021M；3.4 s 内全部消失；1 次 Consume。
    - 复测（--demo multi，每档 9 s，每个图标 4096 个粒子）：High 240.0 fps，p99 4.77 ms、最大 5.10 ms，CPU 每帧 0.57 ms，GPU 0.126 ms；Balanced 240.0 fps，p99 4.77 ms、最大 5.24 ms；Low 58.3 fps。
  - **第十四轮：碎片轨道平面倾斜（对照 NASA TDE 可视化与完整模拟的观察角度）。**
    - 之前碎片轨道在正对观察者的平面里，看起来像平面贴图，看不到真实渲染里最有辨识度的效果。现在恒星轨道在倾斜 68° 的平面里（`DebrisSystem::kTiltDeg`，与可选吸积盘的倾角分开），着色器对这个平面单独求光线穿越点（每个阶数一次，和透镜平面、吸积盘按光子遇到的先后合成），所以：被拉长的气流在近侧会从阴影前面经过；黑洞背后的部分被透镜抬到阴影上方形成拱形，阴影下方还有细的二次像；整体按 cos 68° 透视压缩。
    - 每团气的多普勒因子按真实运动计算：g = (f/E) / (1 − v_Y sin 68°)，朝观察者运动的一侧更亮、更蓝，远离的一侧更暗、更红；冷气颜色 ∝ g³，热气按观测温度 gT 的黑体色、亮度 ∝ (gT)⁴。
    - 松手时图标立即变成它自己的像素（和卡片看起来完全一样），作为一个整体沿轨道运动直到近心点再各自运动，不再在近心点换用另一套绘制，所以倾斜平面里也没有跳变。远处缓慢下落的部分加速播放（r ≥ 48M 时 8 倍，12M 以内为真实速度）。
    - 热气体降低亮度上限、kHeat 170 → 110，使环从白热过渡到黄橙色，不再整片发白。
    - 单元测试：近心点 8.00M（轨道平面内）、1.52 s 时在近心点撕开、943 团气（束缚 292，被吞 377，逃逸 566）、成环 6.04 rad；逃逸的气在倾斜平面里要飞更远才离开视野，最后一团 10.8 s 时离开（测试上限改为 13 s）。
    - 复测（--demo multi，每档 9 s）：High 240.0 fps，p99 4.79 ms、最大 5.33 ms，GPU 0.130 ms；Balanced 240.0 fps，p99 4.81 ms、最大 5.54 ms，GPU 0.121 ms；Low 59.3 fps。
  - **第十三轮：撕裂过程按完整模拟（Price et al. 2024 等）的样子重做：恒星在近心点前保持完整，过近心点后变成一条又长又细的气流。**
    - 去掉"从两个尖端逐渐剥离、剩余部分爆散"：图标在近心点前只有轻微线性潮汐形变；到达近心点（或 r < 3.6M、或 2.8 s 后）时，图标的每个像素（32×32 格）一次性变成一团气，位置正好在卡片上的位置，速度都等于恒星速度（冻结近似），卡片 0.08 s 淡出，不跳变。
    - 此后每团气只沿自己的测地线运动：处在势阱不同深度，能量不同，图标被纯运动学地拉成沿轨道的带子；内半束缚、外半逃逸（实测束缚 423 / 共 1021）。
    - 绘制：每团气画成连到原图标里相邻像素（沿潮汐轴方向）的线段，所以气流再长也是连续的带子，保留图标颜色；相邻点相距超过 min(5M, 0.9r) 时断开（避免穿过黑洞的弦）。被激波加热的气体按热量膨胀变粗，所以束缚的那半绕成发热的弯月形再旋入。
    - 束缚气体可以暂时离开视野再回来（离开 3 倍视野半径或存在超过 16 s 才算消失）；逃逸气体离开视野即消失。
    - 单元测试：近心点 8.00M、1.31 s 时本体变成气、1021 团气（束缚 423，被吞 465，逃逸 556）、成环 5.96 rad、6.7 s 内全部消失。
    - 复测（--demo multi，每档 9 s）：High 240.0 fps，p99 4.84 ms、最大 5.72 ms，GPU 0.094 ms；Balanced 240.0 fps，p99 4.77 ms、最大 5.34 ms，GPU 0.087 ms；Low 59.5 fps。
  - **第十二轮：黑洞不再对文件起反应；拉伸改为线性潮汐形变。**

## 未实现 / 未验证

- 物理：Schwarzschild（不旋转）。没有 Kerr 自旋（GARGANTUA 是近极端 Kerr，阴影偏心、盘的不对称更强）；没有盘的厚度、体积发光、湍流和 Novikov–Thorne 温度谱；观察者在无穷远（正交相机），不模拟近距离视差；背景是"桌面天空"的等距方位映射，反观察者方向（α ≈ π）处有一条细缝；窗口边缘的透镜衰减是为衔接桌面做的非物理处理；盘的纹理是桌面而非物理发光。
