# 液态玻璃调试器（Windows）

双击本文件夹中的 `run_glass_lab.cmd`（仓库根目录的同名脚本也可继续使用）。首次只编译一个小型 Qt 工具；以后直接启动，
不需要编译 Prism，也不要求关闭启动器。使用与当前预览脚本相同的 Qt / MSVC 路径。

调试栏顶部的 **场景 / 材质 / 滑块 / 辅助** 用于切换分类，分类栏在滚动时保持可见。

- **场景**可新增卡片、圆形和胶囊；点击选中后可拖动，拖动右下角手柄或输入宽高调整大小，圆形保持等宽高。原有示例卡片也可调整尺寸。新增形状的位置和尺寸单独保存在 Lab，重新打开会恢复；它们不包含在材质 JSON 或 A/B 对比中。
- **滑块**可开启独立的按压材质，分别调整雾化、折射、反光、浓度、透镜边缘、背景放大、按压响应及宽高倍率；关闭时继续使用全局材质。独立参数参与 Lab 的保存、复制、导入和 A/B 对比；启动器会忽略这些 Lab 专用字段。
- **材质**集中放置全局材质和高级调节；**辅助**包含无障碍选项、截图、导入导出与 A/B 操作。

- 右侧滑块实时调节雾化、透镜、反光、材质浓度、连续圆角和描边。
- **材质对照**提供自定义、常规、清晰、增加不透明度和关闭材质五种模式。
  这些是使用现有 Qt shader 的近似效果；切换模式不会改写你调好的滑块数值。
  清晰模式适合图像背景，需自行检查前景文字对比度；关闭材质时保留控件内容。
- **减少高亮效果**降低反光、镜面和轮廓高光；**提高对比度**提高材质浓度和描边。
  它们是调试器内的模拟开关，不会自动读取 Windows 系统辅助功能设置。
  两项和材质模式参与参数保存、JSON 导入导出及 A/B 对照；旧 JSON 默认使用自定义模式。
- 高级调节分为光学/模糊、光照/颜色、交互/动态，共 21 个数值参数。
  包括折射率、边缘宽度、色散、放大倍率、预模糊范围、饱和度、亮度、
  菲涅耳反射、镜面反光、轮廓高光、投影、光源方向、交互强度/半径和跟随延迟。
  雾化控制锐利/模糊背景的混合，预模糊范围控制共享模糊纹理本身。
- **导入参数** 可粘贴复制出来的 JSON；支持旧版参数，缺少的新字段恢复默认，
  数值超范围会截断，无效数据整份拒绝。新增字段也参与保存、复制和 A/B 对比。
- 切换彩色、纯深色、网格或自选图片背景；开启背景移动检查折射和取样对齐。
- 在样例上移动、按住鼠标检查高光；点击计数可检查事件是否正常传递。
- 顶部导航栏、侧边栏可分别显示/隐藏，页面选择联动；这是材质和交互样例，
  不会触发实际启动器页面或账号操作。
- 玻璃球和卡片可按住拖动，在测试区域内移动；“归位”恢复初始位置。
  玻璃球使用真正的圆形轮廓，卡片继续使用连续圆角。拖动中光学取样随位置更新。
  通用样例共用背景取样；重叠时不额外捕获另一块玻璃的内容。
- **顶部栏 ↔ 侧边栏** 演示侧栏滑入/退出、顶部栏淡入/退出；两处选中标记
  使用移动的玻璃胶囊。原有勾选框仍允许同时显示两栏进行对照。
- 顶部选中胶囊可直接按住横向拖动：超过拖动阈值后轻微放大，并随指针移动速度
  横向拉伸；始终限制在栏内。松手后按胶囊中心吸附到最近菜单项并弹性回落，
  此时才提交选中状态。普通点击和键盘 Enter/Space 仍可切换；减少动态效果时
  保留直接拖动，关闭拉伸与弹跳。参考 liquidGL 菜单演示的 drag/snap 行为，
  使用 Qt Quick 自行实现，未加入 GSAP 或网页运行时。
  透镜采样菜单栏、标签以及栏外一小圈背景，采用清晰玻璃以保持文字可辨；它位于
  独立覆盖层，避免把自身捕获。额外纹理只覆盖带少量边距的菜单区域，而不是整个窗口。
  按住选中胶囊即从中心放大，不必先拖动；放大后的区域可超过菜单栏。
- **搜索展开** 或场景内搜索按钮会展开输入框并获取焦点，Esc 或 × 关闭。
  搜索只是交互样例，不连接游戏实例搜索。场景按钮按住时放大，释放时回弹。
- 场景右下方的玻璃开关参考用户提供的 Figma 截图：灰/绿胶囊轨道，静止时白色
  胶囊滑块，按住时放大并过渡到半透明玻璃。点击或拖动切换，Space / Enter
  可通过键盘操作。它控制样例材质淡入/淡出，开关自身保持可见；减少动态效果时
  不播放滑块拉伸和弹性动画。状态也通过滑块左右位置和文字表示。
- 场景下方的玻璃滑块使用细轨道和白色横向胶囊，按住时过渡到玻璃；支持点击、
  拖动和键盘方向键，展示即时数值和按压反馈；
  它是独立交互样例，不会修改右侧材质参数。搜索框支持展开、输入、清除和取消。
  两个手柄的按压态均使用当前右侧调好的玻璃参数，鼠标位置参与局部折射，没有额外的白色描边；开关只在
  键盘聚焦时显示焦点轮廓。滑块手柄静止宽 40 px、按压宽 50 px。
  开关按压态采用向外取样的凸透镜方向，并对小手柄的按压反馈增加响应；其他
  参数仍来自右侧设置。松开后回到白色胶囊。降低交互强度会同步减弱该反馈。
  按住时两个手柄共享一份“背景＋开关轨道＋滑块轨道”的合成纹理及其模糊纹理，
  手柄本身不进入该纹理，避免递归；松手过渡结束或减少透明度时停止这层取样。
  这是调试器的额外离屏开销，尚未做硬件 GPU 性能测量。
- **靠近时融合** 将可拖动卡片和球放入同一张玻璃表面，用平滑 SDF 并集生成连接
  轮廓、法线和折射；没有叠加两层材质。**让玻璃靠近** 可播放靠近过程，拖动可打断。
  **融合距离** 控制连接范围；目前仅支持这一对卡片和球，不是任意控件自动融合。
- **Frosted Glass** 渐变到更强的背景模糊、较低的折射和反光，再关闭可回到原参数。
  上述动画均响应“减少动态效果”；直接拖动仍跟随指针。
- **记录 A** 保存当前参数；调节后用 **切换 A / B** 来回对比。
- **复制参数** 将 JSON 放入剪贴板，可以直接粘贴给 Codex 继续调整，也可在启动器
  Settings → Liquid Glass → **Paste from Glass Lab** 应用到 Windows 启动器（见
  `core/launcher/project-glass/LIQUID_GLASS_WINDOWS.md`）。
- **保存截图**（Ctrl+Shift+S）写入本文件夹的 `build/captures/`。
- 保存 `shaders/liquidglass.frag` 后自动编译并热更新；**F5** 可手动重新编译。
  编译失败会显示错误并保留上一份可用 shader，不会关闭窗口。

复用生产环境的 `LiquidGlass.qml` 与 `liquidglass.frag`，不是另一套仿制效果。
采用相同的共享背景和半分辨率模糊输出。页面布局、账号、游戏核心不在调试器内加载。
调试器展示单层材质样例，不能代替启动器内嵌套层级、实际内容和硬件性能测试。

参数单独保存到本文件夹的 `build/lab-settings.ini`，不会写入启动器设置。
满意后把参数复制出来，再应用到启动器。调整 QML 后重开调试器即可；只有更改
`main.cpp` / CMake 时才需要运行 `run_glass_lab.cmd --build` 重建工具。

`run_glass_lab.cmd --no-run` 只构建不启动。工具支持 `--smoke` 自动检查初次编译、
第二次 shader 更新及截图，使用独立的测试参数文件。诊断日志位于
本文件夹的 `build/glass-lab.log`。

迁移时已复制旧版的参数和截图。旧版构建目录 `core/build-glass-lab/` 暂时保留；
如果迁移时旧调试器仍在运行，关闭它后可手动将最新的 `lab-settings.ini` 复制到新目录。

参考：[liquid_glass_renderer](https://pub.dev/packages/liquid_glass_renderer) 的光学/材质分离，
[liquidGL](https://github.com/naughtyduk/liquidGL) 的色散、放大和交互控制，
[ybouane/liquidglass](https://github.com/ybouane/liquidglass) 的 Fresnel、镜面光照和阴影参数。
参数映射到本项目的 Qt shader；名称和范围不保证与这些库数值等价，未引入其运行时。
新增参数的默认值沿用此前 shader 的常量，启动器未设置它们时保持原有材质。

材质分层、变体与辅助功能对照参考 [Liquid Glass Reference](https://www.conor.fyi/writing/liquid-glass-reference)。
测试器里的实现是跨平台视觉近似，并非调用苹果原生 Liquid Glass API。
